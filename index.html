    Safety before any check

    Unplug the appliance or switch off its breaker before you move it, open a panel, or clean a filter. If it uses gas, shut the gas supply off before you go past the checks the manufacturer published. Do not open a gas valve, an igniter, or a gas line.

    If you smell gas, leave the area and contact your gas utility or emergency services. If water is reaching the floor, shut the supply valve off. Stop and call a technician when the code returns, when the manufacturer says service is required, or when the check is not on the cited page.

    How a page is built

    We open the manufacturer page, record the code and the checks written there, and link that page. If a code is not on the page, it is not here. Names are plain text. There are no logos and no claim that a brand sponsors this site. Sources and methods.

    Frequently asked questions

    Which error code should I look up?

    Use the code on the appliance display. Search on this page, or open the brand and then the appliance type. Every code page comes from the manufacturer's support page or manual.

    Which water filter should I pick?

    Read the part number on the cartridge you take out and the model number in the manual, then open the filter finder. A model is listed only when the manufacturer lists it.

    When should I stop and call a technician?

    Stop when the code returns, when the manufacturer says service is required, or when the check is not on the cited page. Unplug the appliance before you move it or open a panel.
