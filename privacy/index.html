Privacy Policy

Last updated 16 Nov 2026. This policy explains how Which Error Code, whicherrorcode.com, handles information. Which Error Code is a trade name of Joshua Israel Ventures LLC, a Florida limited liability company.

Analytics

When the site is on its own domain, launch pages can load two analytics tools.

Cloudflare Web Analytics counts page views. It does not use cookies and it does not track you across other sites. The beacon loads with each launch page.

Google Analytics 4 (GA4) stays off until you accept the banner. Consent Mode v2 starts with analytics storage, ad storage, ad user data, and ad personalization denied. The GA4 script is requested only after you accept. Reject leaves that script unloaded. Cookie settings in the footer opens the same choice. Accept allows analytics storage on this site only. Ad storage stays denied, because the site shows no ads. The preview build does not include the Cloudflare beacon or the GA4 script. The site owner pastes the measurement id into the launch build before those hits are sent.

Contact

If you email joshuaofisrael@gmail.com or use the contact form, we receive your name, email address, and message so we can reply. The form is handled by FormSubmit. We keep messages only as long as we need them to respond.

Advertising

The site shows no ads today. If we add ads later, we will update this policy first. You would be able to opt out of personalized advertising at Google Ads Settings and aboutads.info. Where the law requires it, we will ask for consent before advertising cookies are set.

Cookies

These pages do not set their own cookies. Cloudflare Web Analytics does not use cookies. Your banner choice is stored in this browser's local storage, not in a cookie. If you accept Google Analytics 4, Google may set analytics cookies for this site. Choose Reject, or open Cookie settings and reject later, and the GA4 script is not requested.

Hosting

The site is hosted on GitHub Pages, which may log IP addresses for security.

Your rights

You can ask us to access, correct, or delete personal information we hold. Use the contact page. Residents of some states and countries have additional rights, which we will honor.

Children

The site is a general audience site and is not directed at children under 13. We do not knowingly collect personal information from children.

Changes

We will post changes on this page with a new date.
