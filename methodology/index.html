Sources and methods

By Which Error Code. Last verified 16 Nov 2026.

Error codes

A code is added only when it appears on the manufacturer's support page or in the manufacturer's manual. The page on this site names that source. We paraphrase the steps. We do not copy the manual. If the official page says the code means different things on different models, we say that and stop.

What we leave out

Repair blogs, parts sellers, and videos are not sources for a code or a part number. A code that is missing here is missing on purpose. Frigidaire, several Bosch and KitchenAid appliance types, and several filter model numbers are in that gap for this version.

Filters

A filter page uses the manufacturer's product page or performance sheet. We do not copy a compatibility chart from another site. A refrigerator model is listed only when the official page lists it. Third party compatible filters are omitted unless the manufacturer says they are approved.

Safety

The unplug and gas notes are our safety framing. They are separate from the manufacturer's steps, and the page says so when the manufacturer gives a different instruction, as Samsung does for many refrigerator codes.

Dates

Last verified is the date we read the source, 16 Nov 2026. We change that date when the content changes, not on every rebuild.

Report an error.

Which Error Code explains home appliance error codes and refrigerator water filter numbers from the manufacturer pages we cite. We are independent. Names are used only to identify the appliance. Codes and part numbers change by model, so check the manual for yours.
