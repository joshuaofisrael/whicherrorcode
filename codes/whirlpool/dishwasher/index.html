Whirlpool dishwasher error codes

By Which Error Code. Last verified 20 Nov 2026.

These are the Whirlpool dishwasher codes we could read on Whirlpool's own pages on 20 Nov 2026. A code is here only when that page states a cause. F8E4 is water in the drip tray, F9E1 is a long drain, and H2O means the dishwasher is not detecting water.

Safety before any check

Unplug the appliance or switch off its breaker before you move it, open a panel, or clean a filter. If it uses gas, shut the gas supply off before you go past the checks the manufacturer published. Do not open a gas valve, an igniter, or a gas line.

If you smell gas, leave the area and contact your gas utility or emergency services. If water is reaching the floor, shut the supply valve off. Stop and call a technician when the code returns, when the manufacturer says service is required, or when the check is not on the cited page.

How to read the display

On a digital model, Whirlpool says the code appears as an F number and an E number. If the screen is idle, press a button to wake it. On a model with no digits, a flashing Clean light is the code. Count the first burst of flashes. That is F. After a short pause of about 1 to 2 seconds, count the second burst. That is E. A longer pause of about 5 seconds comes before the whole pattern repeats.

Whirlpool's example is seven flashes, a pause, then one flash, which they call an F7E1 reading. The same reading page does not say what F7E1 means. The wash motor code it does define is F7E2. Write the flashes down and use the manual for your model before you treat an undefined pattern as a known code. We do not add F7E1.

Open a code with its own checks

  • Whirlpool F8E4: Water in the Drip Tray

    Water in the drip tray. A professional install uses different steps that leave the power on.

  • Whirlpool F9E1: Dishwasher Will Not Drain

    Long drain. Wash the filter, clear the hose, and check a new disposer's knockout plug.

  • Whirlpool F9E2: Drain Motor Error

    Drain motor code. Hose route and disposer first. Whirlpool does not say to replace the motor.

Codes whose owner page is only a power cut

Whirlpool publishes the same 30 second power cut for the codes in this list, and a different cause line for each one. Unplug a corded dishwasher, or switch off its breaker, wait 30 seconds, and restore power. If the code returns, schedule service. Do not open the control, the wash motor, or the diverter. These codes do not get separate pages, because a second page would repeat that power cut with the name swapped.

  • F1E2: Whirlpool lists the potential cause as a main control communication error. If F1E2 returns, schedule service. Do not open the control.
  • F2E2: Whirlpool lists the potential cause as a main control communication error, the same line it uses for F1E2. If F2E2 returns, schedule service. Do not open the control.
  • F6E1: Whirlpool lists the potential cause as a user interface error on the main control. If F6E1 remains, Whirlpool says to call for service. Do not open the control.
  • F7E2: Whirlpool lists the potential cause as a wash motor error. If F7E2 returns, schedule service. Do not open the wash motor.
  • FAE4: Whirlpool lists the potential cause as a diverter valve error. Also written as F10E4. If FAE4 or F10E4 returns, schedule service. Do not open the diverter.

F1E2 and F2E2 use the same cause line, a main control communication error. Whirlpool does not say which models use which code. F1E1 is the control module code. It has a page of its own because a flashing Clean light is easy to miscount, and because Whirlpool's page for it stops at the power cut. The check is still only that power cut.

Frequently asked questions

How do I read a flashing Clean light on a Whirlpool dishwasher?

Whirlpool says to count the first set of flashes as the F number, pause about 1 to 2 seconds, then count the second set as the E number. A longer pause of about 5 seconds comes before the pattern repeats. Seven flashes, a pause, and one flash is the example they give for an F7E1 reading. They do not define what F7E1 means.

Why is there no F7E1 page?

Whirlpool's reading guide uses F7E1 only as a counting example. The code it actually defines in that family is F7E2, a wash motor error. We do not publish a page for a code the maker does not explain.

Which Whirlpool dishwasher code means it will not drain?

F9E1 is the long drain, with a filter wash and a hose check. F9E2 is the drain motor code, and its owner steps start with the disposer knockout plug and the hose route. Whirlpool does not tell you to replace the motor.
