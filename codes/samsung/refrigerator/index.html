Samsung refrigerator error codes

By Which Error Code. Last verified 16 Nov 2026.

These are the Samsung refrigerator codes we could verify on the manufacturer's own page. Each block says what the code means, the checks that page allows, and when it says to call a technician.

Safety before any check

Unplug the appliance or switch off its breaker before you move it, open a panel, or clean a filter. If it uses gas, shut the gas supply off before you go past the checks the manufacturer published. Do not open a gas valve, an igniter, or a gas line.

If you smell gas, leave the area and contact your gas utility or emergency services. If water is reaching the floor, shut the supply valve off. Stop and call a technician when the code returns, when the manufacturer says service is required, or when the check is not on the cited page.

Samsung's refrigerator code page says not to unplug the refrigerator, and not to clear a code from the panel, unless the steps for that code say to. The unplug line above is for when you have to move the cabinet.

5E

Samsung lists 5E as a fridge defrost sensor error. It is in the common code list, and Samsung says most refrigerator codes need service. Samsung's refrigerator code page says: unless a step tells you to, do not unplug the refrigerator, and do not press buttons to make the code disappear. That can make diagnosis harder. There is no owner repair published for 5E on that page. Request service and leave the code on the display for the technician. Full page for 5E.

8E

Samsung lists 8E as an ice maker (freezer) sensor error. Do not unplug the refrigerator unless a Samsung step for your exact code says to. This is a sensor code, not a filter part number. A filter change is a separate check against the manual. Request service if the code remains. Photograph the display for the technician. Full page for 8E.

40E

Samsung lists 40E and 40C as an ice room fan error. Also listed as 40C. Do not unplug the refrigerator to hide the code. Samsung says that makes diagnosis harder. Make sure food is not packed so tightly that a door cannot close, which is Samsung's related check on fan errors caused by an open door. Request service if the code remains. Full page for 40E.

83E

A power or voltage problem. Samsung lists 83E as abnormal compressor current, 85E as compressor under voltage, 86E as compressor over voltage, and 88 88 as a communication fault during boot. Also listed as 85E, 86E, 88 88. Unplug the refrigerator or switch off the breaker for 60 seconds, then restore power. This is one of the codes where Samsung does tell you to remove power. If the code returns, request service. Full page for 83E.

85C

On Family Hub models, low voltage was detected. Samsung says this can follow a brief power outage and is harmless. Press OK for 3 seconds. Service is not the first step Samsung gives for this code.

OF OF

Cooling Off mode, also called Demo or Shop mode. The lights and controls can work while cooling is off. Samsung says service is not required. Also listed as O FF, OFF OFF. On many outside panels, the common method is to touch and hold the top two buttons on the left side for 5 to 8 seconds until a chime sounds. Some newer models also need the top button on the right. Samsung says to try two buttons first, and to use the manual for your model. Wait and confirm the display does not return to Cooling Off mode. If the display will not leave this mode, use the manual for your model or request help. This is not a cooling failure by itself. Full page for OF OF.

14E

Samsung lists 14E as an ice maker sensor error, in the common code list. Do not clear the code by unplugging unless Samsung's steps for that code say to. Request service. This is not a water filter part number.

Frequently asked questions

Where do these Samsung refrigerator codes come from?

Each code on this page is taken from the Samsung support page linked in Sources. We do not add codes from repair blogs or from another brand.

Does 5E mean the same thing on every Samsung refrigerator?

No. The manufacturer often says a code applies to some models only, or that the same letters mean something else on another model. Check the manual for your model number.

What should I do before I open a panel on a Samsung refrigerator?

Unplug it or switch off the breaker. If it burns gas, shut the gas supply off before any step the manufacturer did not publish. If you smell gas, leave and call your gas utility.
