Samsung dishwasher error codes

By Which Error Code. Last verified 16 Nov 2026.

These are the Samsung dishwasher codes we could verify on the manufacturer's own page. Each block says what the code means, the checks that page allows, and when it says to call a technician.

Safety before any check

Unplug the appliance or switch off its breaker before you move it, open a panel, or clean a filter. If it uses gas, shut the gas supply off before you go past the checks the manufacturer published. Do not open a gas valve, an igniter, or a gas line.

If you smell gas, leave the area and contact your gas utility or emergency services. If water is reaching the floor, shut the supply valve off. Stop and call a technician when the code returns, when the manufacturer says service is required, or when the check is not on the cited page.

4C

The dishwasher is not getting water at the pressure or temperature it needs. Also listed as 4E. Samsung's code page points to its dishwasher water supply guide. Do not reset the code before you follow that guide. Samsung says clearing the code first leaves the cause in place. If the supply is correct and the code returns, request service. Full page for 4C.

5E

The dishwasher cannot drain. Also listed as 5C, SE, SC. Samsung's code page points to its dishwasher is not draining guide. Follow that guide before any reset. If the dishwasher still cannot drain, request service. Full page for 5E.

LC

The leak sensor detects moisture. The dishwasher turns itself on and will not turn off while it tries to drain. Also listed as LE. On Waterwall models, Samsung says this can also mean the water reflector is blocked, so check that too. Do not force the dishwasher off while it is draining a detected leak. Shut off the water supply under the sink if water is reaching the floor. If water has reached the floor, or the code returns, request service. Full page for LC.

HE

The dishwasher is detecting the water temperature incorrectly. Empty the dishwasher, add detergent, and run a normal cycle. If the code remains, switch the breaker off and Samsung says to request service. Full page for HE.

HC

The temperature inside the dishwasher is too hot. Switch the breaker off for 30 seconds and back on. Empty the dishwasher, fill the detergent drawer, and start a Normal cycle. If the error occurs again, Samsung says to request service.

tE

The temperature inside the dishwasher is being detected incorrectly. Empty the dishwasher, add detergent, and run a normal cycle. If the code remains, switch the breaker off and request service. Full page for tE.

OC

There is more water in the dishwasher than there should be. Also listed as 0C, oE. Samsung points this code to its drain and overflow guide. Shut off the water supply if the tub is overfilling onto the floor. Request service if the overfill continues. Full page for OC.

1E

On Waterwall models this is a clogged filter. On Rotary models it is a high temperature heater error. Samsung says the same code pair covers both. Also listed as IE. Waterwall: clean the fine filter at the bottom. Samsung says to use the user manual for that step. Rotary: switch the breaker off for 30 seconds, empty the dishwasher, fill the detergent drawer, and start a Normal cycle. If the code returns, Samsung says to request service. Check the manual so you follow the branch for your model.

9E

There is not enough water in the dishwasher. Empty the dishwasher, add detergent, and run a normal cycle. If the code remains, switch the breaker off and request service.

Frequently asked questions

Where do these Samsung dishwasher codes come from?

Each code on this page is taken from the Samsung support page linked in Sources. We do not add codes from repair blogs or from another brand.

Does 4C mean the same thing on every Samsung dishwasher?

No. The manufacturer often says a code applies to some models only, or that the same letters mean something else on another model. Check the manual for your model number.

What should I do before I open a panel on a Samsung dishwasher?

Unplug it or switch off the breaker. If it burns gas, shut the gas supply off before any step the manufacturer did not publish. If you smell gas, leave and call your gas utility.
