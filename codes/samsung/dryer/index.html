Samsung dryer error codes

By Which Error Code. Last verified 16 Nov 2026.

These are the Samsung dryer codes we could verify on the manufacturer's own page. Each block says what the code means, the checks that page allows, and when it says to call a technician.

Safety before any check

Unplug the appliance or switch off its breaker before you move it, open a panel, or clean a filter. If it uses gas, shut the gas supply off before you go past the checks the manufacturer published. Do not open a gas valve, an igniter, or a gas line.

If you smell gas, leave the area and contact your gas utility or emergency services. If water is reaching the floor, shut the supply valve off. Stop and call a technician when the code returns, when the manufacturer says service is required, or when the check is not on the cited page.

This appliance may burn gas. Shut the gas off before any inspection past the published checks.

tE

The dryer has a temperature problem, or a problem with the sensor that measures temperature. Also listed as tS, t5, tC, tO, t0, tE3, tC5, tCS, 1 tC. Clean the lint screen and the exhaust vent. Samsung says a clogged lint screen or vent trapping heat is the most common cause. If the code continues after the lint screen and the exhaust vent are clean, Samsung says to request service. Full page for tE.

HC

The dryer is getting too hot. Samsung also says some cases are the heater not getting hot enough, which on an electric dryer can be low voltage. Also listed as hE, HC4, 1 HC. Clean the lint screen and the exhaust vent. If the dryer is electric and the code remains, Samsung says to have an electrician check the supplied voltage. If the code continues, Samsung says to request service. Full page for HC.

HC2

Samsung lists HC2 as a gas ignition error. It is in the group with no separate troubleshooting steps. Power the dryer off for 2 to 3 minutes, power it back on, and restart the cycle. The published check stops there. Do not open the burner, the igniter, or the gas line. If the code returns, Samsung says to check the user manual and then request service. Full page for HC2.

dE

The door, the latch, or the sensor that checks them is not secured. Also listed as dC, dF, do, d0, 1 DC, 1 dF. Check that the latch is fixed, that laundry is not caught in the door, and that the door is closed. If the code cannot be cleared, or the door or latch is damaged, Samsung says to request service. Full page for dE.

Clg

These codes appear only after a Vent Blockage test. Clg or Cg means the vent is clogged. C80 or C8 means about 80 percent is clogged. C90 or C9 means over 90 percent is clogged. Also listed as Cg, C80, C8, C90, C9. Clean the lint filter and the exhaust vent. If the test still reports a blocked vent after cleaning, have the vent run checked. Do not keep drying with a blocked exhaust. Full page for Clg.

bE

A button on the panel is stuck or held down. Also listed as bE2, bC2, 6E, 6E2, 6C2. Power the dryer off, then touch and release every button, working across the edges of each one. If a button is damaged, or the code returns after power is restored, Samsung says to request service.

3C

Samsung lists 3C as a motor error, in the group without a separate repair procedure. Power the dryer off for 2 to 3 minutes, power it back on, and restart the cycle. If the code returns, Samsung says to check the manual and then request service. Full page for 3C.

9C1

Something is wrong with the voltage supplied to the dryer. Also listed as 9E, 2E, 9E1. Confirm the dryer is on its own circuit and is not using an extension cord. On an electric dryer, confirm the power cord is installed properly and the correct voltage is supplied. If the code continues, Samsung says to request service. A stacked dryer can also show 9C1 on the washer if you try to control it within 5 seconds of turning the washer on. Samsung says a SmartThings update corrects that case.

Frequently asked questions

Where do these Samsung dryer codes come from?

Each code on this page is taken from the Samsung support page linked in Sources. We do not add codes from repair blogs or from another brand.

Does tE mean the same thing on every Samsung dryer?

No. The manufacturer often says a code applies to some models only, or that the same letters mean something else on another model. Check the manual for your model number.

What should I do before I open a panel on a Samsung dryer?

Unplug it or switch off the breaker. If it burns gas, shut the gas supply off before any step the manufacturer did not publish. If you smell gas, leave and call your gas utility.
